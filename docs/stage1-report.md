## 2. 見つけて直した不具合（重要）

**交差点の区画の予約が、直進の車で半分しか入っていなかった（デッドロックの原因）。**

- 直進の経路は点が2つしかなく、通る区画を「中点の1か所」だけ数えていたため、反対側の区画との衝突が見落とされていました。
- その結果、交差点の中で2台が互いを塞ぎ、**259秒止まり続けて失敗する**ケースが、信号を置く場所によって出ていました（総当たりで発見）。
- 経路を細かく刻んで、通る区画を全部数えるよう修正しました。さらに安全弁として、交差点の中で15秒以上動けない車は、前の車を無視して通します（回数は `forced` として記録。通常は0）。
- **1交差点の旧マップにも、同じ潜在的な不具合があります。** 基準値（87.8／61.0）を保つため、旧マップは修正していません。

## 3. 難しさの調整（C）と、4つの山（B）— 現状

### 不満度ゲージの式（仕様の「平均ベースを想定」からの変更。初期値）

- **旧**: 個人の不満の合計 ÷ max(人数, 25)。ほぼ全員が100にならないと上限に届かず、「何もしないと失敗」が成立しませんでした。
- **新（ステージ1）**: **不満が高い上位20人の平均**（空きは0）。街が広くても薄まらず、混んだ場所の不満が見えます。
- 「上限」は、100ちょうどに張りつくのが現実的でないため、**95以上**（初期値）。これが**ゲーム内2時間**続くと失敗です。
- 不満のたまる速さ: 衝突の不満（無断横断の待ち、渋滞、ヒヤリ）に倍率 **4.5**。信号待ち（歩行者 1.0／車 1.0 /秒）と、遅れ（3/秒）には倍率をかけません。赤信号の待ちは「予期された待ち」として、遅れにも、周りへの伝染にも数えません。

### 結果（種3つの平均。1日の時間帯ごとの「平均／最大／上限（95以上）にいたゲーム内の分」）

最大だけでは、ほとんどが99に張りつくため、平均と、上限にいた時間を併記します。**上限が120分続くと失敗**です。

### 分かったこと・正直な評価

**0. 未達の目標（最優先で直す）: 交差点0に「短い」で1基置くだけで、ほぼクリアできてしまいます。**
上限にいた時間は朝12分・昼2分（失敗は120分）で、種3つとも失敗しません。開発ポイントの経済（開始わずか → バブルで貯める → 途中で追加開発）を使わなくても、最初の1手で足ります。指示書の中心の問い（「循環は面白いか」）が成立していないため、**第2回の最初の課題**にします（誘導員やタップより先）。


1. **置く場所・順番で、結果が分かれます**（交差点0を先にすれば失敗なし、学校前を先にすると失敗）。ステージ1の「置く場所のパズル」としては成立しています。
2. **「何もしないと失敗」は、まだ頼りない**（失敗は3種のうち1つ）。一方で、朝〜昼は信号を1基置いても上限近く（91〜99）に張りつき、**1基では足りない難しさ**です。開発ポイントで2基目以降を置くことが前提になります。
3. **B（4つの山）は部分的にしか成立していません。**
   - 朝と昼（朝の渋滞の尾を引く）は、ほぼ上限です。
   - **夕は20〜48、夜は4〜44で、穏やかすぎます。** 夕（下校、帰宅）と夜（通過交通）が、問題として弱いです。
   - 山ごとの最良の置き方も、ほぼ交差点0で同じです（夜だけ「置かない」が最良）。「朝に置いた信号が、夜には邪魔になる」という判断（取り壊すか）は、夜の不満が **なし19 → 交差点0で30** と出ており、成立の兆しはあります。
4. 昼のゲージが高いのは、**朝の渋滞が昼まで尾を引く**ためです（走行に約1時間かかるため）。企画の「昼は穏やか」とずれています。

### 次に調整したいこと（提案）
- 朝の渋滞が昼にこぼれないよう、通勤の時間帯を前倒し、または北東の交差点（全員が通る）の詰まりを軽くする。
- 夕（下校と帰宅）・夜（通過交通）の需要を上げて、それぞれ別の場所に問題を作る。
- 失敗の確実性を上げる（信号なしで3/3失敗）一方、順番を正しく置けば全種クリアできる幅に。

## 9. Muse の確認が必要な、仕様からの変更点

次の5点は、仕様書（Muse の管轄）の記述から変えています。承認か、別案の指示をお願いします。

1. **ゲージの「上限」を、100ではなく95以上**にした（上位20人の平均が、100ちょうどに張りつくのは現実的でないため）。
2. **ゲージを、平均ではなく「不満の高い上位20人の平均」**にした（街が広いと平均が薄まり、「何もしないと失敗」が成立しないため）。
3. **バブル1個を +10 にした**（提案書は +5）。2基目を朝の山の中に買えるようにするため。
4. **赤信号で待っている間は、遅れにも、周りへの伝染にも数えず、バブルも出さない**ことにした（予期された待ちのため）。
5. **衝突の不満（無断横断の待ち、渋滞、ヒヤリ）にだけ倍率4.5をかけた。** 信号待ちと遅れにはかけていない（難易度の調整用）。
