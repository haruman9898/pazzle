## 実装順（案）

一度に作る必要はないとのことなので、次の順で進めます。

| 弾 | 内容 | 理由 |
|---|---|---|
| **第1弾** | #1 波の演出、#2 不満の理由、#3 熱マップ、#10 の光（朝・昼・夕・夜） | 今の1交差点で作れて、効果がすぐ見える。「置いた効果が見える」という芯を強める |
| 第2弾 | #8 暮らしの密度（役割ごとの見た目）、#9 立ち話・手を挙げる・傘 | 役割（児童／通勤者／買い物客）を作る。第4弾の事後診断が、この役割の数を使う |
| 第3弾 | ステージ1のマップ（交差点4つ、建物）、#5 置く場所の制約、#6 グリーンウェーブ | 複数の信号と、道路の途中への設置が前提になる。設計の大きな変更なので、決めたいことが多い |
| 第4弾 | 結果画面、#4 事後診断、#11 ダイジェスト、#7 再挑戦の★条件 | ★のしきい値が TBD。第2弾の役割と第3弾のマップが前提 |
| 第5弾 | #10 の音（環境音、設置音など） | 仕様では「音は最低限・後回し」。音源の方針（生成 AI など）を決めてから |

## 進捗

### 第1弾（完了）

| 項目 | 内容 |
|---|---|
| 安心の波 | 信号を確定した瞬間、交差点から輪が広がる。輪が通った人は不満が半分になり（赤→白）、少し大きくなって白く光る |
| 不満の理由 | 設置パネルを開いている間（時間停止中）だけ見られる。街全体の内訳（横断待ち・信号待ち・渋滞・遅れ・ヒヤリ・周りの不満）と、人をタップするとその人の理由（上位3つ）が出る |
| 熱マップ | 時間停止中（設置パネル・配置中）だけ、待ちがたまった地面が黄→赤に染まる。冷めるのに約25秒 |
| 時間帯の光 | 夜（月明かりと街灯）→夜明け（オレンジ）→朝（柔らかい）→昼（明るい）→夕（オレンジ）→夜。左下の「朝ピーク／24時間」ボタンで、光の確認用に24時間表示へ切り替えられる（確認用の機能） |

試作で置いた暫定値（`game/scripts/core/tuning.gd`）:

- **波で不満が減る割合 0.5** は、ルールの追加です。Muse の確認が必要です（下記）。
- 熱マップの冷める速さ 25秒、最も赤くなる値 8。
- 24時間表示では、夜の発生量を0.2倍、夕方（17:30）にも朝の0.8倍のピークを置いた（朝ピークの結果は変わらない）。

### 決定（2026-11-24・ユーザー）

- 安心の波で不満が減る割合は **20%**（`WAVE_RELIEF = 0.2`）。
- 「人をタップして理由を見る」仕組みは **廃止**。停止中は、画面左上の「いまの不満の内訳」だけを表示する。
- 傘は **見た目だけ**（雨で交通は変わらない）。

### 第2弾（完了）

| 項目 | 内容 |
|---|---|
| 暮らしの密度 | 歩行者に3つの役割。**児童**=小さく、黄色い帽子とランドセル／**通勤者**=背が高くカバン／**買い物客**=買い物袋。時間帯で比率が変わる（登下校は児童が多い）。肌の色・持ち物の色も個人ごとに違う。車は3つの型（セダン・ハッチバック・バン）と5色。文字は使っていない |
| 仕草 | 歩くと上下に揺れる／横断中は手を挙げる（児童は必ず、大人は一部）／街の人々が立ち話（最大8組。時間帯で増減し、夜はいない。シミュレーションには入らない飾り）／夜は車の前が白く、後ろが赤く光る |
| 雨と傘 | 左下の「晴れ／雨」ボタンで雨に。雨粒、色とりどりの傘（児童は黄色）、濡れて暗くなる路面、灰色がかった光。**交通には影響しない** |
| 確認用の URL | `?t=12`（開始時刻）、`&rain=1`（雨）。例: `…/pazzle/?t=17.5&rain=1`。`t` を付けると24時間表示になる |

役割は今のところ見た目だけで、移動や不満には影響しません（第4弾の事後診断で人数を数えるために持たせています）。

## 決めてほしいこと・共有したいこと

1. **児童の動き**: 仕様では、児童は「徒歩のまま」で、登下校時間に学校の方へ向かいます。今は4つの角のエリアの間を、役割とは無関係に歩いています。学校のある地図（第3弾）で、役割ごとの行き先を決めます。
2. **街の人々（立ち話）の場所**: 今は、歩道のすぐ外側（空き地の縁）に固定して置いています。建物が入る第3弾で、建物の前などに置き直します。
