## 進捗

### 第1弾（完了）

| 項目 | 内容 |
|---|---|
| 安心の波 | 信号を確定した瞬間、交差点から輪が広がる。輪が通った人は不満が半分になり（赤→白）、少し大きくなって白く光る |
| 不満の理由 | 設置パネルを開いている間（時間停止中）だけ見られる。街全体の内訳（横断待ち・信号待ち・渋滞・遅れ・ヒヤリ・周りの不満）と、人をタップするとその人の理由（上位3つ）が出る |
| 熱マップ | 時間停止中（設置パネル・配置中）だけ、待ちがたまった地面が黄→赤に染まる。冷めるのに約25秒 |
| 時間帯の光 | 夜（月明かりと街灯）→夜明け（オレンジ）→朝（柔らかい）→昼（明るい）→夕（オレンジ）→夜。左下の「朝ピーク／24時間」ボタンで、光の確認用に24時間表示へ切り替えられる（確認用の機能） |

試作で置いた暫定値（`game/scripts/core/tuning.gd`）:

- **波で不満が減る割合 0.5** は、ルールの追加です。Muse の確認が必要です（下記）。
- 熱マップの冷める速さ 25秒、最も赤くなる値 8。
- 24時間表示では、夜の発生量を0.2倍、夕方（17:30）にも朝の0.8倍のピークを置いた（朝ピークの結果は変わらない）。

### 決定（2026-11-24・ユーザー）

- 安心の波で不満が減る割合は **20%**（`WAVE_RELIEF = 0.2`）。
- 「人をタップして理由を見る」仕組みは **廃止**。停止中は、画面左上の「いまの不満の内訳」だけを表示する。
- 傘は **見た目だけ**（雨で交通は変わらない）。

| 項目 | 内容 |
|---|---|

**数値（`game/tests/town_test.gd`。朝〜昼前 6:00〜12:00、接触はすべて0）**

| 条件 | 不満の最大 |
|---|---|
| 信号なし | 77.6 |
| 1基だけ置く。最良（交差点0＝北西） | **59.8** |
| 1基だけ置く。学校の前の路上（x=-8, z=2.5） | **60.9** |
| 1基だけ置く。最悪（路上、効果の薄い場所） | **83.1（信号なしより悪い）** |

「置く場所の制約を、設計で使う」が成立しています。学校のある道路の周り（交差点0と学校前の路上）に置くと約60に下がり、車の少ない道路の端などに置くと、効果が薄いか、かえって悪くなります。信号を置きすぎる（交差点0と1の組み合わせなど）と、歩行者の待ちが増えて悪化します。

**連動について（正直な報告）**

- 車だけを流した単独の試験では、連動は成立しています。2つの信号の青のずれで、車の平均停止時間は 15.6秒（同時に青）から 10.1秒（最良のずれ）まで変わります。自動連動が選ぶずれ（7秒）では11.0秒です。
- ただし、ステージ1の需要は歩行者が中心なので、街全体の不満度（ゲージ）には、連動の効果がほとんど出ていません（5つの種の平均で、連動あり・なしが同程度）。
- 連動が効くのは、車の流れが太い道路です。ステージ1では「置く場所」が主役で、連動は後のステージ（車の量が増える）で効く仕組み、という位置づけになりそうです。

## 決めてほしいこと・共有したいこと

1. **誘導員と自転車は、この回に入れていません。** ステージ1の仕様には、誘導員（費用50、朝夕の1時間半だけ稼働）と自転車が含まれます。調整目標の「信号＋誘導員で40以下」は、誘導員がないと確かめられません。次の弾で入れてよいですか。
2. **ステージ1を通常の画面にするか。** 今は `?map=stage1` のときだけです。通常のURLでステージ1が開くようにしてよいですか（1交差点の地図は、確認用に `?map=legacy` などで残せます）。
3. **信号なしの不満の大きさ。** 目標は「信号なしで90〜100」ですが、今は77.6です。ゲージを「街全体の平均」にしているため、街が広いと薄まります。平均のままにするか、「混んでいる場所の不満」を重く見る式にするか、決めてください。
4. **連動の効果。** 上のとおり、ステージ1ではほとんど効きません。連動を主役にしたい場合は、道路の車の量を増やす設計が必要です。
5. **試作で置いた初期値。** 需要の数（通勤者10・児童22・買い物客3、家1軒あたり）、通過交通の量、連動の距離20マスなどは、すべて `game/scripts/core/tuning.gd` の末尾（`T_` で始まるもの）にあります。
